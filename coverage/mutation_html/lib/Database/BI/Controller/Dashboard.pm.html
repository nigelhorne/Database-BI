  661: any C<?f=col:op:val> filters from the query string, and renders
  662: C<dashboard.html.tt>.  Table names must match C<[A-Za-z0-9_]+>; anything
  663: else returns 404.
  664: 
  665: =item C<browse> - C<GET /browse>
  666: 
  667: Filesystem navigator.  Resolves C<?path=> through C<realpath> (returns 404
  668: for non-existent or non-directory paths), then lists directories and
  669: supported files as clickable links.  Defaults to C<$HOME>.
  670: 
  671: =item C<open_file> - C<GET /open>
  672: 
  673: Opens a supported data file from an arbitrary absolute path (C<?path=>).
  674: The path is resolved through C<realpath> and checked against the supported
  675: extension list before instantiating C<DataSource>.  Applies C<?f=> filters.
  676: Sets C<file_path> in the stash so the template can record the file in
  677: C<localStorage> "recently opened".
  678: 
  679: =item C<join_tables> - C<GET /join>
  680: 
  681: Performs one or more left joins in the order given by repeatable C<j=>
  682: parameters, then applies any C<f=> result filters.
  683: 
  684: Query parameters:
  685: 
  686:   l=<spec>               Required. Left table spec: "table:name" or
  687:                            "path:/abs/path".  Returns 404 if unresolvable.
  688:   j=<spec>|<lk>|<rk>    Repeatable join step.  <spec> is a right-table
  689:                            spec; <lk> and <rk> are the left and right key
  690:                            column names.  Invalid or non-existent steps are
  691:                            silently skipped.
  692:   f=<col>:<op>:<val>     Repeatable result filter.  Applied server-side
  693:                            after all joins.
  694: 
  695: Left-join semantics: every left row is kept.  Right-table columns are
  696: appended for rows that match on the join key; unmatched rows get C<undef>
  697: for all right-table columns.  If a right-table column name collides with a
  698: left-table column name the right column is prefixed with
  699: C<< right_label.colname >>.
  700: 
  701: =item C<columns_api> - C<GET /api/columns>
  702: 
  703: Returns C<{ "columns": [...] }> as JSON.  Accepts C<?table=name> (table
  704: from C<data_dir>) or C<?path=/abs/path> (arbitrary file).  Returns 404
  705: when the table or file cannot be found or resolved.  Used by the join panel
  706: to populate the right-key dropdown without a page reload.
  707: 
  708: =item C<export_data> - C<GET /export>
  709: 
  710: Exports the current logical view as a file download.  Accepts the same
  711: C<l=>, C<j=>, and C<f=> parameters as C<join_tables>, plus C<format=>:
  712: 
  713:   format=csv     (default) - RFC 4180 CSV, UTF-8, CRLF line endings;
  714:                    generated without external dependencies.
  715:   format=sqlite  - SQLite 3 database written via DBI/DBD::SQLite to a
  716:                    temporary file, slurped, and returned as
  717:                    application/vnd.sqlite3.  The single table is named
  718:                    C<data>; every column is declared C<TEXT>.
  719: 
  720: Returns 404 if the left table spec is invalid or the table cannot be
  721: opened.  An empty result set (all rows filtered out) exports correctly as
  722: header-only CSV or an empty SQLite table.
  723: 
  724: =back
  725: 
  726: =head2 Filter operators
  727: 
  728: The C<f=col:op:val> filter spec supports:
  729: 
  730:   eq        case-insensitive string equality
  731:   ne        case-insensitive string inequality
  732:   contains  case-insensitive substring match
  733:   starts    case-insensitive prefix match
  734:   lt        numeric less-than
  735:   le        numeric less-than-or-equal
  736:   gt        numeric greater-than
  737:   ge        numeric greater-than-or-equal
  738:   empty     cell is undef or empty string (val ignored)
  739:   notempty  cell is defined and non-empty (val ignored)
  740: 
  741: The colon separator is split with a limit of 3, so values may themselves
  742: contain colons (e.g. C<f=sale_date:eq:2025-01-15>).
  743: 
  744: =head2 Private helpers
  745: 
  746: =over 4
  747: 
  748: =item C<_open_spec($spec)>
  749: 
  750: Parses a C<table:name> or C<path:/abs> spec, checks that the file exists
  751: (C<Database::Abstraction> silently creates empty objects for missing files
  752: - existence must be tested explicitly), and returns C<($datasource, $label)>
  753: or an empty list on failure.
  754: 
  755: =item C<_apply_filter_spec($records, $spec)>
  756: 
  757: Standalone sub.  Parses C<col:op:val> and returns a filtered copy of the
  758: records arrayref.
  759: 
  760: =item C<_apply_filters($self, $records)>
  761: 
  762: Reads all C<f=> query params, applies them in order via
  763: C<_apply_filter_spec>, and returns C<($filtered, \@raw_specs, $json)>.
  764: C<$json> is a script-safe JSON array of C<{col,op,val}> objects used to
  765: pre-populate filter rows in the join panel.
  766: 
  767: =item C<_left_join(...)>
  768: 
  769: Standalone sub.  Performs a single left join and returns
  770: C<(\@merged_records, \@merged_columns)>.
  771: 
  772: =item C<_get_columns($source, $records)>
  773: 
  774: Standalone sub.  Returns the ordered column list from the C<DataSource>
  775: object, falling back to C<id_column>-first alphabetic order when the
  776: backend does not expose column order (SQLite, XML).
  777: 
  778: =item C<_csv_row(@fields)>
  779: 
  780: Standalone sub.  Formats one row of values as an RFC 4180 CSV line (CRLF
  781: terminated).  Fields containing commas, double-quotes, or newlines are
  782: quoted; embedded double-quotes are doubled.
  783: 
  784: =item C<_build_export_url($self, $left_spec, \@join_specs, \@filter_specs)>
  785: 
  786: Method.  Builds a C</export?l=...&j=...&f=...> URL string from the current
  787: view's parameters, suitable for use in HTML C<href> attributes (the caller
  788: must apply C<| html> in TT to escape C<&> to C<&amp;>).
  789: 
  790: =item C<_render_csv($self, $records, \@columns, $name)>
  791: 
  792: Method.  Serialises C<$records> to RFC 4180 CSV and renders it as a UTF-8
  793: download with C<Content-Disposition: attachment; filename="${name}.csv">.
  794: 
  795: =item C<_render_sqlite($self, $records, \@columns, $name)>
  796: 
  797: Method.  Creates a temporary SQLite database, inserts all records into a
  798: table named C<data>, slurps the file, and renders it as a binary download
  799: with C<Content-Disposition: attachment; filename="${name}.db">.  The
  800: temporary file is unlinked immediately after reading.
  801: 
  802: =back

  804: =cut
