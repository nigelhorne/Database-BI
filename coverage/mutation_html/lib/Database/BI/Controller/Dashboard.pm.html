  650: Opens the named table from C<data_dir> via the C<open_table> helper, applies
  651: any C<?f=col:op:val> filters from the query string, and renders
  652: C<dashboard.html.tt>.  Table names must match C<[A-Za-z0-9_]+>; anything
  653: else returns 404.
  654: 
  655: =item C<browse> - C<GET /browse>
  656: 
  657: Filesystem navigator.  Resolves C<?path=> through C<realpath> (returns 404
  658: for non-existent or non-directory paths), then lists directories and
  659: supported files as clickable links.  Defaults to C<$HOME>.
  660: 
  661: =item C<open_file> - C<GET /open>
  662: 
  663: Opens a supported data file from an arbitrary absolute path (C<?path=>).
  664: The path is resolved through C<realpath> and checked against the supported
  665: extension list before instantiating C<DataSource>.  Applies C<?f=> filters.
  666: Sets C<file_path> in the stash so the template can record the file in
  667: C<localStorage> "recently opened".
  668: 
  669: =item C<join_tables> - C<GET /join>
  670: 
  671: Performs one or more left joins in the order given by repeatable C<j=>
  672: parameters, then applies any C<f=> result filters.
  673: 
  674: Query parameters:
  675: 
  676:   l=<spec>               Required. Left table spec: "table:name" or
  677:                            "path:/abs/path".  Returns 404 if unresolvable.
  678:   j=<spec>|<lk>|<rk>    Repeatable join step.  <spec> is a right-table
  679:                            spec; <lk> and <rk> are the left and right key
  680:                            column names.  Invalid or non-existent steps are
  681:                            silently skipped.
  682:   f=<col>:<op>:<val>     Repeatable result filter.  Applied server-side
  683:                            after all joins.
  684: 
  685: Left-join semantics: every left row is kept.  Right-table columns are
  686: appended for rows that match on the join key; unmatched rows get C<undef>
  687: for all right-table columns.  If a right-table column name collides with a
  688: left-table column name the right column is prefixed with
  689: C<< right_label.colname >>.
  690: 
  691: =item C<columns_api> - C<GET /api/columns>
  692: 
  693: Returns C<{ "columns": [...] }> as JSON.  Accepts C<?table=name> (table
  694: from C<data_dir>) or C<?path=/abs/path> (arbitrary file).  Returns 404
  695: when the table or file cannot be found or resolved.  Used by the join panel
  696: to populate the right-key dropdown without a page reload.
  697: 
  698: =item C<export_data> - C<GET /export>
  699: 
  700: Exports the current logical view as a file download.  Accepts the same
  701: C<l=>, C<j=>, and C<f=> parameters as C<join_tables>, plus C<format=>:
  702: 
  703:   format=csv     (default) - RFC 4180 CSV, UTF-8, CRLF line endings;
  704:                    generated without external dependencies.
  705:   format=sqlite  - SQLite 3 database written via DBI/DBD::SQLite to a
  706:                    temporary file, slurped, and returned as
  707:                    application/vnd.sqlite3.  The single table is named
  708:                    C<data>; every column is declared C<TEXT>.
  709: 
  710: Returns 404 if the left table spec is invalid or the table cannot be
  711: opened.  An empty result set (all rows filtered out) exports correctly as
  712: header-only CSV or an empty SQLite table.
  713: 
  714: =back
  715: 
  716: =head2 Filter operators
  717: 
  718: The C<f=col:op:val> filter spec supports:
  719: 
  720:   eq        case-insensitive string equality
  721:   ne        case-insensitive string inequality
  722:   contains  case-insensitive substring match
  723:   starts    case-insensitive prefix match
  724:   lt        numeric less-than
  725:   le        numeric less-than-or-equal
  726:   gt        numeric greater-than
  727:   ge        numeric greater-than-or-equal
  728:   empty     cell is undef or empty string (val ignored)
  729:   notempty  cell is defined and non-empty (val ignored)
  730: 
  731: The colon separator is split with a limit of 3, so values may themselves
  732: contain colons (e.g. C<f=sale_date:eq:2025-01-15>).
  733: 
  734: =head2 Private helpers
  735: 
  736: =over 4
  737: 
  738: =item C<_open_spec($spec)>
  739: 
  740: Parses a C<table:name> or C<path:/abs> spec, checks that the file exists
  741: (C<Database::Abstraction> silently creates empty objects for missing files
  742: - existence must be tested explicitly), and returns C<($datasource, $label)>
  743: or an empty list on failure.
  744: 
  745: =item C<_apply_filter_spec($records, $spec)>
  746: 
  747: Standalone sub.  Parses C<col:op:val> and returns a filtered copy of the
  748: records arrayref.
  749: 
  750: =item C<_apply_filters($self, $records)>
  751: 
  752: Reads all C<f=> query params, applies them in order via
  753: C<_apply_filter_spec>, and returns C<($filtered, \@raw_specs, $json)>.
  754: C<$json> is a script-safe JSON array of C<{col,op,val}> objects used to
  755: pre-populate filter rows in the join panel.
  756: 
  757: =item C<_left_join(...)>
  758: 
  759: Standalone sub.  Performs a single left join and returns
  760: C<(\@merged_records, \@merged_columns)>.
  761: 
  762: =item C<_get_columns($source, $records)>
  763: 
  764: Standalone sub.  Returns the ordered column list from the C<DataSource>
  765: object, falling back to C<id_column>-first alphabetic order when the
  766: backend does not expose column order (SQLite, XML).
  767: 
  768: =item C<_csv_row(@fields)>
  769: 
  770: Standalone sub.  Formats one row of values as an RFC 4180 CSV line (CRLF
  771: terminated).  Fields containing commas, double-quotes, or newlines are
  772: quoted; embedded double-quotes are doubled.
  773: 
  774: =item C<_build_export_url($self, $left_spec, \@join_specs, \@filter_specs)>
  775: 
  776: Method.  Builds a C</export?l=...&j=...&f=...> URL string from the current
  777: view's parameters, suitable for use in HTML C<href> attributes (the caller
  778: must apply C<| html> in TT to escape C<&> to C<&amp;>).
  779: 
  780: =item C<_render_csv($self, $records, \@columns, $name)>
  781: 
  782: Method.  Serialises C<$records> to RFC 4180 CSV and renders it as a UTF-8
  783: download with C<Content-Disposition: attachment; filename="${name}.csv">.
  784: 
  785: =item C<_render_sqlite($self, $records, \@columns, $name)>
  786: 
  787: Method.  Creates a temporary SQLite database, inserts all records into a
  788: table named C<data>, slurps the file, and renders it as a binary download
  789: with C<Content-Disposition: attachment; filename="${name}.db">.  The
  790: temporary file is unlinked immediately after reading.
  791: 
  792: =back
  793: 
  794: =cut
