  372: =head1 NAME
  373: 
  374: Database::BI::Model::DataSource - Table-agnostic adapter around Database::Abstraction
  375: 
  376: =head1 VERSION
  377: 
  378: This document describes Database::BI::Model::DataSource version 0.01.
  379: 
  380: =head1 SYNOPSIS
  381: 
  382:     use Database::BI::Model::DataSource;
  383: 
  384:     my $source = Database::BI::Model::DataSource->new(
  385:         directory => '/path/to/data',

  387:     );

  390:

  393:     }

  398:         table     => 'sales',
  399:         i18n      => My::I18N::Handle->new,
  400:     );
  401: 
  402: =head1 DESCRIPTION
  403: 
  404: C<Database::BI::Model::DataSource> is a thin, table-agnostic adapter that
  405: wraps L<Database::Abstraction> and exposes a single C<fetch_all> method
  406: returning an arrayref of hashrefs.
  407: 
  408: L<Database::Abstraction> is a read-only ORM that discovers data files
  409: (CSV, SQLite, XML, PSV, etc.) automatically from a directory based on the
  410: calling class name.  C<DataSource> generates an ephemeral subclass at
  411: construction time so that callers never interact with
  412: L<Database::Abstraction> directly and so that the backend can be swapped
  413: for L<Database::Join> in Phase 2 without any change to the controller.
  414: 
  415: All user-visible strings and exception messages are keyed through the
  416: C<%MESSAGES> dictionary and routed via C<_msg()>, making every diagnostic
  417: replaceable by an i18n object at instantiation time.
  418: 
  419: =head1 LIMITATIONS
  420: 
  421: =over 4
  422: 
  423: =item *
  424: 
  425: Only read operations are supported.  Write-back is not in scope.
  426: 
  427: =item *
  428: 
  429: One C<DataSource> instance corresponds to exactly one table.  Use
  430: C<Database::Join> (Phase 2) to query across multiple tables.
  431: 
  432: =item *
  433: 
  434: The ephemeral backend class is generated into a package namespace
  435: (C<Database::BI::_DB::*>) that persists for the lifetime of the process.
  436: Instantiating two C<DataSource> objects for the same table name reuses
  437: the same ephemeral class.
  438: 
  439: =item *
  440: 
  441: The C<i18n> object, if supplied, must implement C<maketext($key, @args)>
  442: compatible with L<Locale::Maketext>.
  443: 
  444: =back
  445:

  447: 
  448: No environment variables are read.  All configuration is passed through
  449: the constructor.
