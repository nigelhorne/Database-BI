  116: =head1 NAME
  117: 
  118: Database::BI::Extract -- SQLite materialisation cache for Database::BI
  119: 
  120: =head1 SYNOPSIS
  121: 
  122:   use Database::BI::Extract;
  123: 
  124:   my $cache = Database::BI::Extract->new(model_dir => '.bi');
  125: 
  126:   # Check cache
  127:   my $path = $cache->get($spec, $mtime, $size);
  128:   unless ($path) {
  129:       my $bytes = ...; # build the SQLite file
  130:       $path = $cache->put($spec, $mtime, $size, $bytes);
  131:   }
  132: 
  133: =head1 DESCRIPTION
  134: 
  135: Stores SQLite materialisation files (extracts) under C<model_dir/extracts/>.
  136: The cache key is an MD5 of the dataset spec, its source mtime, and its size.
  137: Deleting the extracts directory leaves the application fully functional.
