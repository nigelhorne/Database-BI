  122: =head1 NAME
  123: 
  124: Database::BI::Extract -- SQLite materialisation cache for Database::BI
  125: 
  126: =head1 SYNOPSIS
  127: 
  128:   use Database::BI::Extract;
  129: 
  130:   my $cache = Database::BI::Extract->new(model_dir => '.bi');
  131: 
  132:   # Check cache
  133:   my $path = $cache->get($spec, $mtime, $size);
  134:   unless ($path) {
  135:       my $bytes = ...; # build the SQLite file
  136:       $path = $cache->put($spec, $mtime, $size, $bytes);
  137:   }
  138: 
  139: =head1 DESCRIPTION
  140: 
  141: Stores SQLite materialisation files (extracts) under C<model_dir/extracts/>.
  142: The cache key is an MD5 of the dataset spec, its source mtime, and its size.
  143: Deleting the extracts directory leaves the application fully functional.
  144: 
  145: This is a standalone cache class.  The web application does not call it; the
  146: caller decides when to build an extract, and the class only stores and finds
  147: the bytes.
  148:

  158: 
  159: =head4 OUTPUT
  160: 
  161: A C<Database::BI::Extract> object.  Croaks C<model_dir is required> without
  162: C<model_dir>.  Nothing is created on disc until C<put>.
