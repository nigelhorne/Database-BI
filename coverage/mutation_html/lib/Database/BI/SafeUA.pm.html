  243: =head1 NAME
  244: 
  245: Database::BI::SafeUA - Fetch a URL only if it leads to the public internet
  246: 
  247: =head1 VERSION
  248: 
  249: 0.023.1
  250: 
  251: =head1 SYNOPSIS
  252: 
  253:     my $ua  = Database::BI::SafeUA->new(private_hosts => ['intranet.example.com']);
  254:     my $res = $ua->get('https://example.com/table.html');
  255:     # http://localtest.me/ -> 403 "Refused: localtest.me is 127.0.0.1, which is this machine"
  256: 
  257: =head1 DESCRIPTION
  258: 
  259: An L<LWP::UserAgent> for C<url:> sources and C</import>.  Every request,
  260: including each redirect (at most 5), is resolved, refused with a C<403>
  261: response if any address is on this machine, a private or shared network,
  262: link-local (cloud metadata services), multicast or reserved, and then sent to
  263: the address that was checked.  The name stays in the C<Host> header, the TLS
  264: server name (SNI) and the certificate check, so DNS that answers differently
  265: on a second lookup (rebinding) changes nothing.  An IPv4 address inside IPv6
  266: (mapped, NAT64, compatible, 6to4) is checked as that IPv4 address.  Only
  267: C<http> and C<https> are fetched.
  268: 
  269: =head1 METHODS
  270: 
  271: =head2 new
  272: 
  273: =head3 API SPECIFICATION
  274: 
  275: =head4 INPUT
  276: 
  277:     private_hosts: arrayref of host names, optional; names (or *.suffix) that
  278:                    may resolve to private addresses (an intranet).  An address
  279:                    written as such is never one of them.
  280:     resolve:       code ref, optional; host -> list of address strings (tests)
  281:     anything else: as LWP::UserAgent->new (timeout 30, max_redirect 5 by default)
  282: 
  283: =head4 OUTPUT
  284: 
  285: The user agent.
  286: 
  287: =head2 send_request
  288: 
  289: As L<LWP::UserAgent/send_request>, with the checks above.  LWP calls it for
  290: every request and each redirect; callers use C<get> and the rest as usual.
  291: 
  292: =head3 API SPECIFICATION
  293: 
  294: =head4 INPUT
  295: 
  296:     $request: HTTP::Request
  297:     $arg, $size: as LWP::UserAgent (content file or callback, read size)
  298: 
  299: =head4 OUTPUT
  300: 
  301: An L<HTTP::Response> whose C<request> is the one given (not the pinned copy).
  302: A refused request gets C<403 Refused: E<lt>whyE<gt>> and C<Client-Warning: Internal
  303: response>, and nothing is sent: a scheme other than http or https, no host, a
  304: name that does not resolve, or any address C<blocked_address> refuses (unless
  305: C<private_host_allowed> allows the name).
  306: 
  307: =head2 private_host_allowed
  308: 
  309:     $ua->private_host_allowed('reports.corp.example');   # 1 with private_hosts => ['*.corp.example']
  310: 
  311: =head3 API SPECIFICATION
  312: 
  313: =head4 INPUT
  314: 
  315:     $host: a host name (case does not matter)
  316: 
  317: =head4 OUTPUT
  318: 
  319: 1 when C<private_hosts> names it, or a C<*.suffix> entry ends it (C<*.corp.example>
  320: matches C<a.corp.example>, not C<corp.example> or C<evilcorp.example>), else 0.
  321: C<send_request> asks this only for a name, never for an address written as one.
  322:
