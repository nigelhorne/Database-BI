  605: =head1 NAME
  606: 
  607: Database::BI::Insights - Automatic statistical insights for Database::BI (Phase 5.2)
  608: 
  609: =head1 SYNOPSIS
  610: 
  611:     use Database::BI::Insights;
  612: 
  613:     my $insights = Database::BI::Insights::compute(
  614:         records  => \@rows,
  615:         columns  => \@cols,

  618:     );
  619: 
  620: =head1 DESCRIPTION
  621: 
  622: Pure-arithmetic insight detection.  No LLM, no external service calls.
  623: Detects four classes of insight:
  624: 
  625: =over
  626: 
  627: =item outlier
  628: 
  629: A value beyond the Tukey IQR fence (Q1 - 1.5*IQR or Q3 + 1.5*IQR).
  630: 
  631: =item period_delta
  632: 
  633: Overall period-over-period delta between the most recent two month-periods
  634: visible in a date column.
  635: 
  636: =item top_mover
  637: 
  638: The dimension member with the largest period-over-period absolute change.
  639: Requires at least one categorical column and one date column.
  640: 
  641: =item seasonality
  642: 
  643: Detected via lag-1 autocorrelation on monthly totals.  A coefficient >= 0.6
  644: is flagged.  Requires at least 8 distinct month-periods.
  645: 
  646: =back
  647: 
  648: Every insight includes a C<view_url> that links to the chart or stats view
  649: showing the underlying data.  An insight without a clickable view_url is a bug.
  650: 
  651: =head1 FUNCTIONS
  652: 
  653: =head2 compute(%args)
  654: 
  655:     my $insights = Database::BI::Insights::compute(
  656:         records  => \@rows,     # arrayref of row hashrefs
  657:         columns  => \@cols,     # arrayref of column names
  658:         spec_key => $l,         # l= spec string
  659:         base_url => $url,       # request URL, used only as a fallback
  660:     );
  661: 
  662: Returns an arrayref of insight hashrefs.  Each hashref has:
  663: 
  664:     kind      -- 'outlier' | 'top_mover' | 'period_delta' | 'seasonality'
  665:     headline  -- one short sentence
  666:     detail    -- numbers that substantiate the headline
  667:     view_url  -- URL to the view showing the data
  668:     method    -- key for method_note()
  669: 
  670: =head2 method_note($key)
  671: 
  672: Returns a one-sentence description of the algorithm behind C<$key>.
  673: 
  674: =head1 ALGORITHM NOTES
  675: 
  676: =head3 Outliers
  677: 
  678: Tukey IQR fence: Q1 - 1.5*IQR and Q3 + 1.5*IQR.  Requires at least 4 values
  679: per group.  Results are sorted by distance from the nearest fence; up to 5
  680: outliers are reported per column.
  681: 
  682: =head3 Period-over-period
  683: 
  684: Year-month (YYYY-MM) buckets from ISO-8601 date columns.  Requires at least
  685: 2 distinct periods.
  686: 
  687: =head3 Seasonality
  688: 
  689: Lag-1 autocorrelation r(1) on the sequence of period sums.
  690: Formula: r(1) = cov(y[t], y[t+1]) / var(y[t]).
  691: Threshold: r >= 0.6.  Requires at least 8 distinct month-periods.
