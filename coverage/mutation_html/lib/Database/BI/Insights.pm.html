  600: 
  601: Database::BI::Insights - Automatic statistical insights for Database::BI (Phase 5.2)
  602: 
  603: =head1 SYNOPSIS
  604: 
  605:     use Database::BI::Insights;
  606: 
  607:     my $insights = Database::BI::Insights::compute(

  612:     );
  613: 
  614: =head1 DESCRIPTION
  615: 
  616: Pure-arithmetic insight detection.  No LLM, no external service calls.
  617: Detects four classes of insight:
  618: 
  619: =over
  620: 
  621: =item outlier
  622: 
  623: A value beyond the Tukey IQR fence (Q1 - 1.5*IQR or Q3 + 1.5*IQR).
  624: 
  625: =item period_delta
  626: 
  627: Overall period-over-period delta between the most recent two month-periods
  628: visible in a date column.
  629: 
  630: =item top_mover
  631: 
  632: The dimension member with the largest period-over-period absolute change.
  633: Requires at least one categorical column and one date column.
  634: 
  635: =item seasonality
  636: 
  637: Detected via lag-1 autocorrelation on monthly totals.  A coefficient >= 0.6
  638: is flagged.  Requires at least 8 distinct month-periods.
  639: 
  640: =back
  641: 
  642: Every insight includes a C<view_url> that links to the chart or stats view
  643: showing the underlying data.  An insight without a clickable view_url is a bug.
  644: 
  645: =head1 FUNCTIONS
  646: 
  647: =head2 compute(%args)
  648: 
  649:     my $insights = Database::BI::Insights::compute(
  650:         records  => \@rows,     # arrayref of row hashrefs
  651:         columns  => \@cols,     # arrayref of column names
  652:         spec_key => $l,         # l= spec string
  653:         base_url => $url,       # request URL, used only as a fallback
  654:     );

  656: Returns an arrayref of insight hashrefs.  Each hashref has:
  657: 
  658:     kind      -- 'outlier' | 'top_mover' | 'period_delta' | 'seasonality'

  660:     detail    -- numbers that substantiate the headline
  661:     view_url  -- URL to the view showing the data
  662:     method    -- key for method_note()

  665: 
  666: Returns a one-sentence description of the algorithm behind C<$key>.
  667: 
  668: =head1 ALGORITHM NOTES
  669: 
  670: =head3 Outliers
  671: 
  672: Tukey IQR fence: Q1 - 1.5*IQR and Q3 + 1.5*IQR.  Requires at least 4 values
  673: per group.  Results are sorted by distance from the nearest fence; up to 5
  674: outliers are reported per column.
  675: 
  676: =head3 Period-over-period
  677: 
  678: Year-month (YYYY-MM) buckets from ISO-8601 date columns.  Requires at least

  681: =head3 Seasonality
  682: 
  683: Lag-1 autocorrelation r(1) on the sequence of period sums.
  684: Formula: r(1) = cov(y[t], y[t+1]) / var(y[t]).
  685: Threshold: r >= 0.6.  Requires at least 8 distinct month-periods.
