11# Which language a message is given in, and the text it is given as.
12#
13# Every module keeps its messages in British English, in its own %MESSAGES.
14# Another language is a module of its own, Database::BI::I18N::<code>, holding
15# for each package only the messages that read differently; a message it does
16# not list is the British one.  American English (en_us) differs in a handful
17# of spellings, so that is all it holds.
18#
19# The language is chosen by CGI::Lingua, in choose(), from an Accept-Language
20# header or, on the command line, the locale (from_locale()).  A request sets
21# $LANGUAGE for as long as it is being answered (Database::BI's around_dispatch
22# hook, with local), so a message raised anywhere under it - a model's croak
23# included - is in the reader's language without the language being passed
24# down.  A script sets it from the locale when it starts.  Nothing else does:
25# a module called from other code gives its messages in British English, so
26# what it croaks with does not depend on the environment it happens to run in
27# (a test suite run under LANG=en_US.UTF-8 matches the British messages).
28
