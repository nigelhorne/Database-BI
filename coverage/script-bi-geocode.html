1#!/usr/bin/env perl
2# bi-geocode -- Phase 6 geocode-cache warming CLI for Database::BI
3#
4# Opens a dataset spec, geocodes every distinct value of the named column
5# (or of several, --col repeated, joined with ", ": an address, then its country),
6# and writes the resolved coordinates into the shared geocode cache in
7# models.json.  Subsequent map views for the same dataset serve from the
8# cache without making any geocoder requests.
9#
10# Places are looked up in Geo::Coder::Free's local data first, then on
11# OpenStreetMap (Nominatim) at one a second, with no limit on how many: the
12# map page asks Nominatim for at most map_geocode_online_max places, and this
13# script is how the rest are found.  --offline keeps every lookup local.
14#
15# The script is idempotent: a second run against the same column with a
16# warm cache resolves zero additional places (and says so).
17#
18# Usage:
19#   bi-geocode --spec <l-spec> --col <column> [--col <column> ...]
20#              [--data-dir <dir>] [--model-dir <dir>]
21#              [--openaddr <path>] [--region <CC>]
22#              [--offline] [--online-max <n>]
23#              [--dry-run] [--verbose]
24#
25# Exit codes:  0 = ok
26#              1 = column not found or no records loaded
27#              2 = bad arguments / data source unavailable
28#
29# Suitable for cron:
30#   0 2 * * * cd /opt/myapp && ./script/bi-geocode \
31#       --spec table:customers --col city --region US --verbose
