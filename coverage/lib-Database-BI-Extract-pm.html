14# An extract is a SQLite materialisation of one dataset, stored at:
15#   <model_dir>/extracts/<fingerprint>.db
16#
17# The fingerprint is md5_hex(spec . "\0" . mtime . "\0" . size).
18# It is a pure cache: deleting the extracts/ directory at any time leaves
19# the application fully functional.  No file under data_dir is created.
20#
21# This is a standalone cache class: the web application does not call it (the
22# routes read their sources directly), and the tests cover the class itself.
23# A caller decides whether to build a new extract; Extract only stores and
