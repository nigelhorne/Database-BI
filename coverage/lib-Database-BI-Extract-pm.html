15# An extract is a SQLite materialisation of one dataset, stored at:
16#   <model_dir>/extracts/<fingerprint>.db
17#
18# The fingerprint is md5_hex(spec . "\0" . mtime . "\0" . size).
19# It is a pure cache: deleting the extracts/ directory at any time leaves
20# the application fully functional.  No file under data_dir is created.
21#
22# This is a standalone cache class: the web application does not call it (the
23# routes read their sources directly), and the tests cover the class itself.
24# A caller decides whether to build a new extract; Extract only stores and
25# retrieves bytes.
