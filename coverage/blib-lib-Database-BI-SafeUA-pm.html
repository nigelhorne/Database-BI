14# The fetcher for url: sources and /import.  A page that names a URL gets the
15# server to fetch it, so the URL must not lead to this machine or a private
16# network (SSRF): an admin page on 127.0.0.1, a database on 10.x, a cloud's
17# metadata service on 169.254.169.254.  Checking the URL's text is not enough
18# (a name such as localtest.me, or one whose DNS answers 127.0.0.1, says
19# nothing in its text), and resolving it first is not enough either: LWP
20# resolves again when it connects, and a name can answer differently the
21# second time (DNS rebinding).  So every request, redirects included, is
22# resolved here, refused if any address is not public, and sent to the
23# address that was checked, with the name kept for the Host header, the TLS
24# server name and the certificate check.
