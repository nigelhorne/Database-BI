15# ---------------------------------------------------------------------------
16# An extract is a SQLite materialisation of one dataset, stored at:
17#   <model_dir>/extracts/<fingerprint>.db
18# or, when a cache directory is set (see new), at:
19#   <cache_dir>/database-bi-extracts/<fingerprint>.db
20#
21# The fingerprint is md5_hex(spec . "\0" . mtime . "\0" . size).
22# It is a pure cache: deleting the extracts/ directory at any time leaves
23# the application fully functional.  No file under data_dir is created.
24#
25# The web application reads an accelerated dataset's extract through get(), and
26# script/bi-extract builds one through put() (Dashboard::accelerate).  A caller
27# decides whether to build a new extract; Extract only stores and retrieves
28# bytes.
29# ---------------------------------------------------------------------------

32# than in it: evict() removes every .db file it finds, and a CACHEDIR such as
