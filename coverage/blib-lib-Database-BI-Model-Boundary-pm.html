3# The outline of the area each map marker is in: its county, for now.
4#
5# A map can draw the boundary of the county around each of its markers.  The
6# outlines come from OpenStreetMap's Nominatim, through its reverse lookup:
7# given a point and a zoom, it names the administrative area there and, with
8# polygon_geojson, sends its shape.  Asking by point rather than by name means
9# the same code serves coordinate columns and geocoded places, in any country,
10# and needs no state or country column to tell one Richmond from another.
11#
12# Nominatim allows one request a second, so this module asks as little as it
13# can:
14#
15#   1. Each point is rounded to 3 decimal places (about 110 m), which is also
16#      all of it that leaves this machine, and remembered with the outline it
17#      fell in (or with none, for a point at sea).
18#   2. A point not remembered is first tested against the outlines already
19#      known, through an index of their bounding boxes, so ten thousand shops
20#      in one county cost one request, not ten thousand.
21#   3. Only then is Nominatim asked, at most online_max times a call, and a
22#      point it does not answer is left pending, not remembered as nowhere.
23#
24# The outlines are simplified by Nominatim (polygon_threshold), a few KB each,
25# because they are written into the page.
26#
27# The level is a "county": the division of a country below its states.  Which
28# of Nominatim's place ranks that is depends on the country, so %LEVELS gives a
29# rank for most (12: a US county, an English county, a German Landkreis, a
30# French departement, a Pakistani district) and the countries that differ (10:
31# an Indian or Bangladeshi district, a Chinese prefecture, a Spanish province;
32# 8: a Kenyan county), and config map_bounds_ranks can add more.  Each reply
33# names its country, so a point is asked at the zoom of the last country seen,
34# and again at its own country's zoom when that guess was wrong: one extra
35# request at each border a map crosses.  The rank an outline was accepted at is
36# kept with it, so a changed table asks again rather than draw the old level.

=head1 NAME

Database::BI::Model::Boundary - The county outline around each map marker

=head1 VERSION

0.022.0

=head1 SYNOPSIS

    use Database::BI::Model::Boundary;

    my $boundary = Database::BI::Model::Boundary->new(
        cache  => Database::BI::Model::Boundary->file_cache('.bi'),
        online => 1,
    );

    my $result = $boundary->outlines([ [ 39.09, -77.64 ], [ 38.85, -77.31 ] ]);
    $map->add_geojson(
        { type => 'FeatureCollection', features => $result->{features} },
        name => 'County boundaries',
    );

    # A point the map page listed as pending, looked up on its own
    my $answer = $boundary->lookup_point($result->{pending}[0]);

=head1 DESCRIPTION

Finds the county each point is in and returns its outline as a GeoJSON
Feature, for L<HTML::OSM>'s C<add_geojson>.  The outlines come from
OpenStreetMap's Nominatim reverse lookup, through the same throttled user agent
as the geocoder (L<Database::BI::Model::Geocode/nominatim_ua>), so the two
together never ask more than once a second.

Only the point is sent, rounded to three decimal places (about 110 metres).
Every answer is cached: a point with the outline it is in, and the outline
itself.  A point inside an outline already known is matched here, without a
request, so many points in one county cost one lookup.

A county here is the division of a country below its states, whose place rank
in Nominatim depends on the country: 12 (a US county or independent city, an
English county, a German Landkreis, a French departement) unless the country is
listed otherwise: 10 for India, Bangladesh, China and Spain (district,
prefecture, province), 8 for Kenya.  C<ranks> adds or changes countries.
Anything else Nominatim answers is taken as "no county here" and remembered as
such.  A country with nothing at its rank (Australia, Brazil, Japan) gets no
outlines.

Each reply names the point's country, so a point is asked at the zoom of the
last country seen, and asked again when its own country wants another rank.
An outline is kept with the rank it was accepted at; when C<ranks> changes, the
points it covered are asked again.
